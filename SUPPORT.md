# Support

Looking for help with **verloc**? Choose the right channel below so you get the fastest answer:

- **Documentation & deployment guides:** Start with the [verloc README](https://github.com/getverloc/verloc#readme).
- **Questions, usage tips, and architecture ideas:** Post in [GitHub Discussions](https://github.com/getverloc/verloc/discussions).
- **Reproducible bugs & feature requests:** Open a structured issue in [GitHub Issues](https://github.com/getverloc/verloc/issues/new/choose).
- **Security vulnerabilities:** Do not open a public issue — submit a [Private Security Advisory](https://github.com/getverloc/verloc/security/advisories/new).
